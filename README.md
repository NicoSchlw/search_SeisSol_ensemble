# Search SeisSol ensemble and visualize output

This repository contains a script that compares observed waveforms with an ensemble of SeisSol models and provides the best-fitting model.

### Find the best-fitting model

The best-fitting SeisSol model can be found by running the script `search_catalog_for_best_fit_model.sh`:

```
obsdir='path/to/TABOO_waveforms'
ensemble_dir='path/to/catalog_scenario'
eq_time='2023,3,9,19,8,6.0'
python3 search_catalog_for_best_fit_model.py $eq_time $obsdir $ensemble_dir 
```

Make sure to adjust the `obsdir`, `ensemble_dir`, and the earthquake origin time `eq_time` as needed.

### Generate shake maps

Ground motion parameter distribution plots can be generated by running the script `run_plot_shakemaps.sh`:

```
filename="data-surface-GME.xdmf"
python3 plot_shakemaps.py $filename
```
